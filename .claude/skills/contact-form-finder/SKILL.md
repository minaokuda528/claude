# Contact Form Finder（問い合わせフォームURL調査スキル）

企業・店舗リストの各行について、公式サイトURL(または会社名)を手がかりに
**問い合わせフォーム(お問い合わせ／contact)ページのURL**を調べて補完する。

## 前提と制約（最初に必ず確認・共有する）

- **調査は Web 検索(WebSearch)ベース**で行う。この環境から個別サイトへ直接HTTPアクセス
  できない場合がある(プロキシのネットワークポリシー、認証必須ページ、`docs.google.com`
  等がブロックされる)。取得したURLは検索結果で確認したものであり、
  **ページを開いての最終動作確認まではできないことがある**旨を成果物とチャットの両方で明示する。
- **Google スプレッドシート等への直接書き込みは、書き込み対応コネクタが無ければできない。**
  本スキルの成果物は「貼り付け用CSV/列データ」まで。書き込みは
  (a) 書き込み対応 Google Sheets コネクタ、(b) Claude in Chrome、(c) 手動貼り付け のいずれか。
- 大量件数(数百件)になり得る。**進捗は逐一 CSV に追記して保存**し、中断・再開できるようにする。

## 入力の受け取り方

1. ユーザーからCSV(またはシートのエクスポート)を受け取る。文字コードは日本語想定(UTF-8/CP932)。
2. 列構成を読み、以下をユーザーに確認 or 推定する:
   - **公式サイトURL列**(例: 「公式URL」「Webサイト」「HP」)。無い場合は**会社名列**で代替検索。
   - **出力先列**(例: 「問い合わせフォームURL」)。既存値がある行は原則スキップ。
   - **抽出条件**(任意。例: 「公式URLはあるが問い合わせフォームURLが空欄、かつ対応日が空欄の行のみ」)。
3. 見つからなかった行の出力値の希望を確認する(デフォルトは空欄。ユーザー指定で `ー` 等)。

## 手順

### 1. 対象行の抽出
`scripts/extract_targets.py` を使い、条件に合う行だけを抽出する。
列名・条件はコマンド引数で渡す(スクリプト内ヘルプ参照)。
抽出結果(行番号・会社名・公式URL)を一覧化し、総件数をユーザーに伝える。

> 行番号は**元CSVの行番号(ヘッダー=1行目)**で管理する。抽出行は連続しないため、
> 出力は必ず「行番号 + 値」の対応で持ち、単純な一列ペースト前提にしない。

### 2. フォームURLの検索(バッチ処理)
WebSearch を使い、**1回のアシスタント応答で4件程度**まとめて検索する(並列)。
各社のクエリは次を基本に組み立てる:

- 独自ドメインがある場合: `<会社名 or ドメイン> お問い合わせ` / `<domain> contact`
- 楽天/Yahoo等モール店の場合: `<店舗名> <モール> 運営会社 お問い合わせ`
  → 運営会社を特定し、その**自社サイトのフォーム**を探す。

判定ルール:
- `/contact/`, `/inquiry/`, `/otoiawase/`, `お問い合わせ`, `contact` 等を含む**フォームページのURL**を採用。
- 法人向けと個人向けが分かれる場合は**用途に合う方を主**にし、他方や電話/メールは備考へ。
- **モール店(楽天など)は独立フォームを持たないことが多い**(連絡はモールのログイン必須メッセージ
  機能経由)。その場合はフォームURLを空にし、備考に**運営会社名・メール・電話**を記載する。
- 同名企業が複数ある場合は所在地・業種で取り違えを避け、備考に注意書きを付す。

### 3. 逐次記録
検索1バッチごとに `scripts/append_results.py`(または直接CSV追記)で
`results.csv`(列: 行番号, 会社名, 問い合わせフォームURL, 備考)へ**必ず保存**する。
これにより長時間・大量でも中断-再開が可能。

### 4. 成果物の生成
全件終了後、`scripts/build_output.py` で最終CSVを2種類作る:
- **調査結果CSV**: 行番号 / 会社名 / 公式URL / 問い合わせフォームURL / 備考(メール・電話・注意点)
- **記入用CSV**: 行番号 / 会社名 / H列に入れる値。見つからなかった行はユーザー指定の値
  (デフォルト空欄、指定があれば `ー` 等)。
SendUserFile で `display: "attach"` として渡す。

### 5. 反映方法の案内
シートへの直接記入を求められたら、上記「前提と制約」に従い
(a)書き込み対応コネクタ / (b)Claude in Chrome / (c)手動貼り付け を提示する。
Claude in Chrome 用には、記入用CSVと共に「行番号の行のH列へ3列目の値を入れる。既存値は
上書きしない」といった明確な指示文を添える。

## スクリプト
- `scripts/extract_targets.py` … CSVから条件抽出(列名・空欄条件を引数指定)
- `scripts/append_results.py` … 1件/複数件を results.csv に追記
- `scripts/build_output.py` … results.csv と元CSVから最終CSV(調査結果・記入用)を生成

## 品質チェック
- 総件数 = 見つかった件数 + 見つからなかった件数 が抽出件数と一致するか検算する。
- 少なくとも数件はフォームURLを実際に開いて妥当性を確認するようユーザーに促す。
- 「Web検索ベースで未確認箇所がある」旨を最終報告に必ず含める。
