# エラー処理ガイド（Skillが停止・分岐の判断に使う）

## 基本方針
- **データエラーがある状態で確定資料を作らない。** エラー時は停止し、内容と対処を日本語で提示する。
- 不明な数値を補完しない。欠損・算出不可はその旨を表示する（0にしない）。
- 迷ったら人に確認する。勝手に仮定して進めない。

## スクリプトの終了コード
| コード | 意味 | Skillの動作 |
|---|---|---|
| 0 | 正常 | 次の工程へ進む |
| 1 | 実行時エラー（ファイル無し・形式不正など） | 停止。原因と対処を提示 |
| 2 | 検証エラー（データ矛盾など） | 停止。エラー一覧を提示し、修正または承認を求める |

## よくあるエラーと対処

| 状況 | 兆候 | 対処 |
|---|---|---|
| 会社設定が無い | `company-settings.yaml` が見つからない | 初期設定モードへ案内（setup-guide.md） |
| ファイルを開けない | 文字コードエラー / ファイル無し | UTF-8かShift_JISで保存し直す／パスを確認 |
| 必須列不足(E-001) | 媒体・職種・応募数・広告費のいずれか無し | 列名を確認。`column_aliases` で対応付け |
| 数値以外(E-002) | 数値列に文字が混在 | 該当セルを数値に修正 |
| マイナス値(E-003) | 実数がマイナス | 元データを確認 |
| 面接>応募(E-010)/採用>面接(E-011) | 件数の整合が取れない | 元データの値を確認 |
| 合計不一致(E-020) | 合計行と明細の合計が違う | 管理画面と照合。承認後は明細合計で続行（--allow-total-mismatch） |
| 個人情報列 | 氏名・電話などの列 | 該当列を削除して再提出 |

## 警告（続行するが必ず伝える）
前月なし(新規)・目標なし(未設定)・空欄・未登録媒体・異常単価・大幅変動・応募0件・費用0円で応募あり。
これらはレポートの「要確認事項」へ反映する。

## PowerPoint検証でエラーが出たら
数値不一致・空白スライド・特殊値未変換などが出た場合は納品せず、原因を特定して再生成する。

## 停止時の伝え方（例）
```
データ検証でエラーが1件見つかりました。確定資料は作成していません。
・E-020 合計不一致: 合計行の応募数(103)が明細合計(98)と一致しません。
対処: 媒体管理画面の値と照合してください。
明細合計(98)を正として進めてよろしければ、その旨お知らせください（承認後に続行します）。
```
