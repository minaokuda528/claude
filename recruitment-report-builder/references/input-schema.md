# 入力データ仕様（input-schema）

正式対応: CSV / Excel(.xlsx)。補助対応: PDFから利用者がCSV/Excelへ転記したもの
（PDF直接読み込みは非対応。転記時は人による数値確認が必須）。

## 文字コード
UTF-8（BOM可）または Shift_JIS。自動判定する。

## 当月・前月データ（明細行）

| 内部項目 | 想定列名の例 | 型 | 必須 | 備考 |
|---|---|---|---|---|
| media | 媒体, 媒体名, メディア | 文字列 | 必須 | 表記揺れは媒体マスタ/エイリアスで統一 |
| job_category | 職種, 職種名 | 文字列 | 必須 | 前後空白を除去 |
| location | 拠点, 勤務地, エリア | 文字列 | 任意 | 未設定可 |
| period | 対象期間, 期間, 年月 | 年月 | 任意 | 無ければ実行時に指定。YYYY-MM へ統一 |
| impressions | 表示数, 表示回数 | 整数≥0 | 任意 | |
| clicks | クリック数 | 整数≥0 | 任意 | |
| applications | 応募数, 応募件数 | 整数≥0 | 必須 | |
| interviews | 面接数, 面接設定数 | 整数≥0 | 任意 | |
| hires | 採用数, 採用人数 | 整数≥0 | 任意 | |
| cost | 広告費, 広告費用, 費用, 掲載費 | 数値≥0(円) | 必須 | カンマ・円記号可（除去される） |
| note | 備考, メモ | 文字列 | 任意 | |

- 数値は「22,000」「120,000円」「3.3%」などの表記でも可（正規化で除去）。
- **空欄は欠損**として扱い、0とは区別する（勝手に0にしない）。
- 合計行がある場合、媒体名が「合計/総計/計/total」または媒体空+応募数ありの行を合計行と判定する。

## 目標データ

| 内部項目 | 想定列名 | 必須 | 備考 |
|---|---|---|---|
| media / job_category / location | 媒体 / 職種 / 拠点 | キー | 明細と対応付け |
| target_applications | 応募数目標 | 任意 | |
| target_cpa | 応募単価目標 | 任意 | |
| target_hires | 採用数目標 | 任意 | |

目標が無い求人は目標比「未設定(NOT_SET)」となる。

## 列名が特殊な場合
会社設定の `column_aliases`（列名→内部項目）で対応付ける。
媒体名の表記揺れは `media.aliases` または `media-mapping.csv` で対応付ける。

## 個人情報
氏名・電話・メール・住所などの列があると処理を停止する。該当列を削除して再提出する。
