# 初期設定ガイド（Claudeが初期設定モードで読む）

会社設定が無いとき、または利用者が初期設定を希望したときの進め方。
**非技術者が迷わず答えられること**を最優先にする。

## 進め方の原則

- 質問は**一度に全部出さない**。1グループ5〜8問ずつ提示する。
- 専門用語には必ず言い換えを添える（例: 「応募単価（応募1件あたりの広告費）」）。
- 「わからない」「未設定」を必ず選べるようにする。後から変更できると伝える。
- 一度答えた内容は聞き直さない。
- 各グループの最後に、入力内容を要約して確認する。
- 全グループ終了後、設定内容の一覧（確認画面）を提示し、**承認を得てから**ファイルを保存する。
- 設定は `settings/<会社名>/company-settings.yaml` のように会社ごとに分けて保存する。

## 質問グループ（この順で進める）

### グループ1: 基本情報（5問）
1. 会社名は？
2. 部署名は？（無ければ空欄で可）
3. 資料の名前は？（既定: 「求人媒体 月次結果報告書」）
4. 報告する相手は？（例: 上司、クライアント。任意）
5. 今回の対象は何年何月ですか？（例: 2026年6月）／比較する前月データはありますか？

### グループ2: 媒体設定（5〜6問）
6. 使っている求人媒体をすべて教えてください（例: Indeed、求人ボックス、エンゲージ）。
7. データはCSVですか、Excelですか？
8. 媒体名の書き方が資料によってバラつくことはありますか？（例: indeed と Indeed）→ あれば対応表を作ります。
9. 必ず載せたい数値はどれですか？（応募数・採用数・応募単価 など）
10. 参考として載せたい数値はどれですか？（表示数・クリック数・面接数 など）
11. 列名が特殊な場合、その列が何を表すか教えてください（例: 「掲載料金」＝広告費）。

### グループ3: 目標設定（5問）
12. 応募数の目標はありますか？
13. 採用数の目標はありますか？
14. 応募単価の目標はありますか？（1件あたりいくらまで、など）
15. 採用単価の目標はありますか？
16. 広告予算はありますか？
※すべて「無ければ未設定でOK」。目標が無い項目は資料で「未設定」と表示されます。

### グループ4: 資料設定（6問）
17. 必要なスライドはどれですか？（既定の10種から不要なものを外せます）
18. 文体は「です・ます調」でよいですか？
19. サマリーの長さは？（短め／標準／長め）
20. ブランドカラー（会社の色）はありますか？（例: 赤系 #C8102E。無ければ既定の紺）
21. ロゴを入れますか？（初期版は差し替え用の枠のみ）
22. 既存のPowerPointテンプレートはありますか？（あれば構成の参考にします。数値は流用しません）

### グループ5: 分析設定（5問）
23. 最も重視するKPIは？（例: 応募単価、採用数）
24. 「好調」と判断する目安は？（例: 目標達成、前月比+20%以上。既定あり）
25. 「注意」と判断する目安は？（例: 応募単価が目標の1.2倍以上。既定あり）
26. 改善を優先する基準は？（例: 応募0件で費用発生。既定あり）
27. 使ってほしくない表現はありますか？（例: 「絶対」「必ず成功」）

## 設定の矛盾チェック（保存前に必ず実施）

`scripts/validate_settings.py` で確認する。代表的な矛盾:

- 必須KPIに `cpa`（応募単価）があるのに、応募数・広告費のどちらかを取得しない設定
- 必須KPIに `cph`（採用単価）があるのに、採用数を取得しない設定
- `brand_color` が16進カラーの形式でない
- `current_period` / `previous_period` が YYYY-MM 形式でない
- 目標比を重視する設定なのに、対応する目標がすべて未設定
- `media.registered` が空（媒体が1つも登録されていない）

矛盾があれば、どこをどう直せばよいかを日本語で提示し、利用者に確認する。

## 確認画面（保存前）

以下の形で要約し、承認を求める。

```
【設定内容の確認】
会社名: 〇〇 / 部署: 〇〇 / 資料名: 〇〇 / 対象: 2026-06（前月: 2026-05）
媒体: Indeed, 求人ボックス, エンゲージ（表記揺れ対応: 3件）
必須KPI: 応募数・広告費・応募単価 / 任意KPI: 表示数 ほか
目標: 応募数=あり / 採用数=あり / 応募単価=一部未設定
スライド: 10種すべて / 文体: です・ます調 / 色: 紺(#2E5E8C) / ロゴ: なし
重視KPI: 応募単価 / 避ける表現: なし
未設定の項目: 採用単価の目標
この内容で保存してよろしいですか？（はい／修正したい）
```

承認後に `company-settings.yaml`（必要なら `media-mapping.csv` も）を保存する。
