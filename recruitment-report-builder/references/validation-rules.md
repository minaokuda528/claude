# 検証ルール（データ検証 + PowerPoint検証）

## 1. データ検証（validate_data.py）

`scripts/validate_data.py` が実施。詳細は `demo/expected-errors.md`。

### エラー（E-xxx）: 検出時はレポート作成を停止

| コード | 内容 |
|---|---|
| E-001 | 必須列不足（媒体・職種・応募数・広告費） |
| E-002 | 数値以外の値 / 必須項目の空欄 |
| E-003 | マイナス値 |
| E-010 | 応募数より面接数が多い |
| E-011 | 面接数より採用数が多い |
| E-020 | 合計行と明細合計の不一致 |

### 警告（W-xxx）: 続行するがレポートへ明記

| コード | 内容 |
|---|---|
| W-001 | 前月データなし（新規掲載） |
| W-002 | 目標値未設定 |
| W-003 | 空欄セル（欠損。0と区別） |
| W-004/005/014/020/021/022 | 正規化の報告（媒体名・数値形式・空白・列名） |
| W-006 | 重複行の疑い |
| W-007 | 未登録媒体 |
| W-010 | 応募単価が警告閾値超過 |
| W-011 | 前月比の大幅変動 |
| W-012 | 応募0件 |
| W-013 | 広告費0円で応募あり |

## 2. PowerPoint検証（generate_pptx.py の validate_pptx / test_generate_pptx.py）

生成後に自動チェックする項目。`--validate-report` で結果CSVを出力できる。

| 項目 | 検証方法 | 判定 |
|---|---|---|
| ファイルが正常に開く | python-pptx で再読込できる | エラー（開けなければ致命） |
| スライド数 | 期待枚数（既定10、除外設定を反映）と一致 | エラー |
| 空白スライド | 各スライドにテキストまたは図形がある | エラー |
| タイトルの重複 | 全スライドのタイトルが一意 | 警告 |
| スライド番号 | 各スライドに番号テキストがある | 警告 |
| 数値の一致 | スライドの主要数値がCSVの値と一致 | エラー |
| 算出不可の表示 | N/A由来のセルが「0」でなく「算出不可」等 | エラー |
| テキストのはみ出し | 文字数がテキストボックス幅に対して過大でないか（目安） | 警告 |
| オブジェクトの重なり | 図形の外接矩形が大きく重なっていないか | 警告 |
| 文字サイズ | 本文が10pt以上、タイトルが20pt以上 | 警告 |
| グラフ凡例 | グラフに凡例またはデータラベルがある | 警告 |

## 3. 目視確認（画像書き出し）

`--export-images` 指定時、LibreOfficeで各スライドをPNG化し `slides/` へ保存する。
LibreOfficeが無い環境ではスキップし、その旨をログに残す（処理は失敗させない）。
目視では次を確認する: 改ページの不自然さ、装飾過多、グラフの可読性、全体の余白バランス。

## 4. 検証の通過基準（フェーズ5完了条件に対応）

- ファイルが正常に開く（エラー0件）
- 数値が正解データ（kpi_results.csv / kpi_by_group.csv）と一致
- 全スライドに必要な情報がある（空白なし）
- レイアウトに大きな崩れがない（重なり・はみ出しの警告が許容範囲）
- テンプレートを企業別に変更できる（テーマ色・ロゴ枠が設定から差し替え可能）
