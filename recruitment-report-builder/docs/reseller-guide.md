# 担当者（あなた）向けガイド — テスト方法とお客様への説明

このツールは「**Claudeに日本語で頼むと、Claudeが計算スクリプトを動かしてレポートとPowerPointを作る**」仕組みです。
あなたもお客様も、プログラムを書く必要はありません。覚えることは「頼み方」と「確認すること」だけです。

---

## パート1: まず仕組みを3行で理解する

1. お客様は、求人媒体の結果ファイル（CSV/Excel）をClaudeに渡す。
2. Claudeが数値を計算し、間違いを自動チェックし、要点のまとめとPowerPointを作る。
3. 最後は必ず人（お客様）が数値と内容を確認して仕上げる。

> ポイント: 数値はすべてスクリプトが計算します。Claudeが数字を勝手に作ることはありません。
> データにおかしな点があると、途中で止まって教えてくれます（間違った資料を作りません）。

---

## パート2: あなたが「1回テスト」する手順（約10分）

**目的**: 実際の動きを自分の目で見て、お客様に説明できるようにする。
**準備**: 何も要りません。練習用の架空データ（デモ）が最初から入っています。

### 手順

1. **Claudeを開く**（このプロジェクトが入ったClaude Code、またはclaude.ai）。
2. Claudeに、次の文章を**そのままコピーして送る**:

   ```
   recruitment-report-builder のデモを実行してください。
   demo フォルダの当月・前月・目標データを使い、
   検証 → KPI計算 → サマリー作成 → PowerPoint作成まで通してください。
   合計と明細が合わない箇所は、承認済みとして明細合計で進めてください。
   最後に、作られたスライドの画像（contact-sheet）を見せてください。
   ```

3. Claudeが順番に実行し、結果を見せてくれます。次の点を**あなたの目で確認**してください。

   - 途中で「合計と明細が合いません」と**エラーを見つけて止まる**こと（＝安全に止まる仕組み）。
   - 応募0件の求人が「0」ではなく「**算出不可**」と表示されること。
   - サマリーが「**事実／示唆／要確認**」に分かれていること。
   - PowerPointが**10枚**でき、グラフと表の数字が合っていること。

4. これで「一通り」を体験できました。お客様にも同じ流れを見せられます。

> もし文章を送っても動かない場合は、「requirements.txt のライブラリを入れてから実行して」と
> 追加で伝えてください。Claudeが準備から行います。

### （参考）詳しい人がコマンドで試す場合

技術担当の方は、`README.md` の「コマンドで試す」の手順で同じことができます。
非技術者の方はこの参考部分は読み飛ばして構いません。

## パート3: お客様への説明のしかた（そのまま話せます）

### 30秒の説明

> 「毎月の求人媒体の報告書を、ファイルを渡すだけで作れる仕組みです。
> 数値は自動で計算し、間違いも自動でチェックします。
> グラフや表を手入力する必要がなくなり、最後の確認に集中できます。」

### 見せる順番（デモ、約8分）

`docs/demo-scenario.md` に台本があります。要点だけ言うと:

1. **Before**: 今までは数値を手で転記してPowerPointを作っていた（時間・ミスが多い）。
2. **実演**: デモデータでClaudeに頼む → 表記のゆれを自動でそろえる。
3. **見どころ**: 合計が合わないデータで**止まる**。「間違った資料を作らない」ことを強調。
4. **仕上げ**: サマリーとPowerPointが自動で完成。数字はすべて計算結果。
5. **After**: 毎月ファイルを渡すだけ。会社ごとに色や目標を変えられる。

### お客様に必ず伝える3点

- 最終的な数値と表現の確認は、**人が行う**（ツールは作成を助けるもの）。
- **応募者の個人情報が入ったファイルは使わない**（入っていると自動で止まります）。
- PDFの自動読み取りなど、**対応していない部分もある**（詳細は `docs/limitations.md`）。

## パート4: お客様への「実行の指示」（お客様に渡す依頼文）

お客様には、次のように依頼してもらえばOKです。そのまま渡せます。

### ① 初回だけ（設定）

> 「自社用の求人媒体レポートを設定したいです。」

→ Claudeが質問するので答えるだけ。分からない項目は「未設定」でOK。
（詳しい手順は `docs/customer-setup-manual.md`）

### ② 毎月（レポート作成）

> 「今月の求人媒体レポートを作りたいです。当月・前月・目標のファイルを添付します。」

→ ファイルを添付して送る。数値・サマリーを確認し、良ければ
> 「この内容でPowerPointを作ってください。」
と伝える。
（詳しい手順は `docs/operation-manual.md`）

### 困ったとき

> 表示されたメッセージ（「E-」や「W-」で始まる番号など）をそのままClaudeに伝える。

（対処一覧は `docs/troubleshooting.md`）

## まとめ: あなたがやること

| タイミング | やること |
|---|---|
| 今 | パート2の文章を送って、1回デモを体験する |
| お客様に紹介 | パート3の台本で説明・実演する |
| 納品 | ZIPと `docs/` のマニュアルを渡す |
| お客様の運用開始 | パート4の依頼文を渡す。初回の数値照合を必ず案内する |

分からないことが出たら、Claudeに「どうすればいい？」と聞けば案内します。
