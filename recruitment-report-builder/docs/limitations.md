# 制限事項一覧

初期版（1.0）で対応していない、または注意が必要な事項をまとめます。
詳細な検討経緯は `docs/open-questions.md` を参照してください。

## 入力形式

- **正式対応**: CSV（UTF-8 / Shift_JIS）、Excel(.xlsx)。
- **補助対応**: PDFから利用者がCSV/Excelへ転記したもの（PDF直接読み込みは非対応。転記後は人による数値確認が必須）。
- 非対応: 画像・スクリーンショット、媒体管理画面からの自動取得。
- Excelは先頭シートを既定使用（`--sheet` で指定可。複数シートの自動統合はしない）。

## 数値・集計

- 前月比・目標比は「応募数」「応募単価」の2軸のみ（他KPIの比較は未対応）。
- 媒体別・職種別・拠点別の集計行の「応募単価目標比」は常に「未設定」（グループ合算の定義が曖昧なため。明細行では算出）。
- 対応期間は月次のみ（週次・日次は非対応）。

## PowerPoint

- スライド画像への書き出しは、LibreOfficeが使えない環境ではPillowによる**近似**レンダリング。
  最終的な体裁は、生成された `.pptx` をPowerPoint / Googleスライドで開いて確認してください。
- ロゴは差し替え用の枠のみ（画像の自動埋め込みは初期版では未実装）。

## サマリー

- サマリー本文の作成はClaudeが担当（スクリプトは構造化JSONまで生成）。
- PowerPoint作成前に、人によるサマリーと数値の確認が前提。

## 運用・セキュリティ

- 応募者個人情報を含むファイルは処理を停止します（列名で検知）。
- 認証情報（媒体のID/パスワード）は設定に保存しません。
- 複数企業の一括処理は未対応（1社ずつ実行）。

## 将来拡張として分離している機能（初期版に含めない）

Google Drive自動監視 / ファイル追加起点の自動実行 / Slack通知 / Gmail送信 /
定期レポート生成 / 媒体管理画面への自動ログイン / PDFの完全自動数値抽出 /
複数企業の一括処理 / Webダッシュボード / データベース保存 / 採用管理システム（ATS）連携。

## 人による確認が必要な工程（自動化しない）

1. 初回設定内容の承認
2. データ検証でエラー・警告が出た際の判断
3. サマリー（分析・改善案）の確認（PowerPoint作成前）
4. PowerPoint完成後の最終確認
5. 初回利用時の数値照合（媒体管理画面との突き合わせ）
