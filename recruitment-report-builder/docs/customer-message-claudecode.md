# お客様へのお渡し連絡文（Claude Codeアプリを使っている人向け・超やさしい版）

前提: お客様はすでに Claude Code アプリを持っていて、使ったことがある。
やることは「フォルダを送る → 開く → 決まった言葉を貼る」だけ。

---

## 送るもの（2つ）

1. **ZIPファイル**: `recruitment-report-builder-1.0.0.zip`
2. 下の連絡文（本文にコピペ）

---

## 連絡文①: 最初に送るメッセージ（コピペOK）

> こんにちは！
> 求人媒体のレポートを自動で作れるフォルダを送ります（ZIP）。
> Claude Code を使って、かんたんに動かせます。
>
> 【やること 3ステップ】
> ① 送ったZIPを保存して、**解凍**する（ダブルクリックでOK）
> ② Claude Code で、その**フォルダを開く**
> ③ チャットに、次の文をそのまま貼って送る👇
>
> ―――――――――――――――
> このフォルダの recruitment-report-builder を使います。
> まず requirements.txt のライブラリを入れてください。
> そのあと、demo フォルダのデータでデモを最後まで実行して、
> できたスライドの画像（contact-sheet）を見せてください。
> 合計が合わない所は、承認済みとして明細合計で進めてください。
> ―――――――――――――――
>
> これで、練習用データで自動レポートができるところまで見られます。
> 分からなければ、画面に出た文をそのまま私に送ってください👌

---

## 連絡文②: デモのあと「本番」に進むメッセージ（コピペOK）

> デモが動きましたね！次は本番の設定をしましょう。
> Claude Code のチャットに、次の文を貼って送ってください👇
>
> ―――――――――――――――
> 自社用の求人媒体レポートを設定したいです。
> ―――――――――――――――
>
> するとClaudeが質問します。会社名・使っている媒体・目標などを、
> 聞かれるまま答えるだけでOKです。
> **分からない項目は「未設定」**と答えて大丈夫。あとで変えられます。

---

## 連絡文③: 毎月のメッセージ（コピペOK）

> 今月のレポートを作りましょう。
> 求人媒体からダウンロードした**今月のファイル**を、
> Claude Code のフォルダに入れて、チャットにこう送ってください👇
>
> ―――――――――――――――
> 今月の求人媒体レポートを作りたいです。今月のファイルを入れました。
> （前月・目標のファイルもあれば使ってください）
> ―――――――――――――――
>
> 数字とまとめを見て、OKなら「この内容でパワーポイントを作ってください」と送れば完成です。

---

## お客様に必ず伝える3つ（短く）

> ・応募者の名前・電話・メールが入ったファイルは入れないでね（自動で止まります）
> ・数字は、最初のうちは媒体の管理画面と見比べてね
> ・「算出不可」「新規」「未設定」は間違いじゃないよ（データがない・計算できない印）

---

## あなた（担当者）向け・サポートのコツ

- お客様が詰まったら、「**画面に出た文をそのまま送って**」と言えばOK。あなたがClaudeに聞けば直し方が分かります。
- 初回だけは、できれば**画面共有か電話**で一緒に。②のデモが動くのを一緒に見ると安心します。
- つまずきやすいのは「フォルダを開く」ところ。
  → Claude Code で「フォルダを開く（Open Folder）」から、解凍した `recruitment-report-builder` を選ぶ、と案内。

### よくある質問への即答

| お客様の質問 | あなたの返事 |
|---|---|
| どのフォルダを開くの？ | 解凍してできた「recruitment-report-builder」を開いてね |
| エラーが出た | その文をそのまま送って。直し方を返すね |
| ライブラリって何？ | 計算に使う部品。最初の1回だけClaudeが入れてくれるよ |
| 数字が合ってるか不安 | 管理画面と見比べよう。合ってれば大丈夫 |
| 毎月なにを送るの？ | 今月ぶんのファイル1つでOK。前月・目標はあれば一緒に |

---

## まとめ（3ステップだけ）

1. **ZIPを送る**（+ 連絡文①）
2. お客様が「解凍 → フォルダを開く → 文を貼る」でデモ体験
3. うまくいったら 連絡文② → ③ で本番・毎月へ
