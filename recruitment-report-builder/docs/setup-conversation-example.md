# 初期設定の会話例（デモ用）

非技術者の利用者とClaudeの、初期設定モードのやり取り例。
実際の質問は5〜8問ずつに分け、「わからない」を許容します。

---

**利用者**: 自社用の求人媒体レポートを設定したいです。

**Claude**: 承知しました。いくつか質問しながら設定ファイルを作ります。専門用語には説明を添えます。「わからない」「まだ決めていない」でも大丈夫で、後から変更できます。まずは基本情報から5つ伺います。

1. 会社名を教えてください。
2. 部署名は？（無ければ空欄で構いません）
3. 資料の名前は？（既定は「求人媒体 月次結果報告書」）
4. 報告する相手は？（例: 上司、クライアント。任意）
5. 今回の対象は何年何月ですか？　比較する前月のデータはありますか？

**利用者**: 会社名は「株式会社サンプル採用企画」、部署は「採用マーケティング部」。資料名は既定でいいです。報告先は採用責任者。対象は2026年6月で、前月の5月データもあります。

**Claude**: ありがとうございます。次は媒体についてです。

6. 使っている求人媒体をすべて教えてください。
7. データはCSVですか、Excelですか？
8. 媒体名の書き方がバラつくこと（例: indeed と Indeed）はありますか？
9. 必ず載せたい数値はどれですか？（応募数・採用数・応募単価 など）
10. 参考に載せたい数値はどれですか？（表示数・クリック数・面接数 など）

**利用者**: Indeed、求人ボックス、エンゲージの3つ。CSVです。たまに「求人BOX」と書かれたりします。必ず載せたいのは応募数・広告費・応募単価。参考は表示数・クリック数・面接数・採用数も。

**Claude**: 「求人BOX」→「求人ボックス」への対応表を作っておきます。続いて目標です。無ければ「未設定」で構いません。

11. 応募数の目標は？
12. 採用数の目標は？
13. 応募単価の目標（1件いくらまで）は？
14. 採用単価の目標は？
15. 広告予算は？

**利用者**: 応募数と採用数は求人ごとに目標があります。応募単価も大体決めています。採用単価は決めていません。予算は月60万円くらい。

**Claude**: 採用単価は「未設定」にしておきます。次は資料の見た目です。

16. 必要なスライドは？（既定は10種。不要なら外せます）
17. 文体は「です・ます調」でよいですか？
18. サマリーの長さは？（短め／標準／長め）
19. ブランドカラー（会社の色）はありますか？
20. ロゴを入れますか？（初期版は差し替え枠のみ）

**利用者**: スライドは全部でいいです。です・ます調で、長さは標準。色は紺っぽいのが好みですが、正確な色番号はわかりません。ロゴは今はなしで。

**Claude**: 紺系の既定色（#2E5E8C）を設定し、後で正確な色番号がわかれば変更できます。最後に分析の方針です。

21. 最も重視するKPIは？
22. 「好調」「注意」の目安は決めていますか？（決めていなければ標準の基準を使います）
23. 使ってほしくない表現はありますか？

**利用者**: 一番大事なのは応募単価です。好調・注意の基準は標準でお任せ。「絶対」みたいな言い切りは避けたいです。

**Claude**: 承知しました。内容を確認します。

```
【設定内容の確認】
会社名: 株式会社サンプル採用企画 / 部署: 採用マーケティング部
資料名: 求人媒体 月次結果報告書 / 報告先: 採用責任者
対象: 2026-06（前月: 2026-05 あり）
媒体: Indeed, 求人ボックス, エンゲージ（表記揺れ: 求人BOX→求人ボックス）
必須KPI: 応募数・広告費・応募単価 / 任意KPI: 表示数・クリック数・面接数・採用数
目標: 応募数=あり / 採用数=あり / 応募単価=一部あり / 採用単価=未設定 / 予算=60万円
スライド: 10種すべて / 文体: です・ます調 / 長さ: 標準 / 色: 紺(#2E5E8C) / ロゴ: なし
重視KPI: 応募単価 / 判定基準: 標準 / 避ける表現: 「絶対」
未設定: 採用単価の目標
この内容で保存してよろしいですか？（はい／修正したい）
```

**利用者**: はい、それで。

**Claude**: 設定を保存しました（`settings/株式会社サンプル採用企画/company-settings.yaml`）。矛盾チェックも問題ありませんでした。毎月は、当月のCSV（あれば前月・目標）をお渡しいただければレポートを作成します。採用単価の目標は、決まりましたらいつでも追加できます。
