# Codex への依頼文（このままコピペして渡してください）

Googleスプレッドシートを直接読み書きして、企業リストの「問い合わせフォームURL」を
自動で調べて記入するツールを実装してください。毎日12時(日本時間)に自動実行します。

## 背景・目的
「整形済み_診断サイト受託」というシートに企業/店舗の一覧があります。
各行の **G列「公式URL」** にサイトURLがあるのに **H列「問い合わせフォームURL」** が空欄の行について、
その会社の**問い合わせフォーム(お問い合わせ / contact)ページのURL**を自動で探し、**H列に直接書き込む**
ツールが欲しいです。見つからなかった行には全角ハイフン **「ー」** を書き込みます。

## 対象スプレッドシート
- スプレッドシートID: `1J748-Kt8OOxlOh6iEfLv6Viya9nuzBB1xVsZ38jZdS0`
- シート名: `整形済み_診断サイト受託`（gid=1487244236）
- 列（ヘッダーは1行目、データは2行目以降）:
  - A:営業軸 / B:ターゲット業界 / C:業界カテゴリ / D:取得元 / E:会社名 / F:店舗名/サービス名
  - **G:公式URL** / **H:問い合わせフォームURL** / I:メールアドレス / J:電話番号 / K:優先度
  - L:アプローチ方法 / M:ステータス / **N:対応日** / O:エラー内容 / P:その他 / Q:担当者 / R:メモ

## やってほしいこと（要件）
1. **サービスアカウントでGoogle Sheets APIに接続**し、上記シートを読み取る。
   - 事前準備手順（サービスアカウント作成、鍵JSON、シートをSAのメールにEditor共有）もREADMEに書く。
2. **対象行の抽出**: `G列が非空` かつ `H列が空` かつ `N列が空` の行のみ処理する。
   - すでにH列に値がある行・N列(対応日)が入っている行は**触らない**。
3. **問い合わせフォームURLの自動発見**（詳細ロジックは `SPEC.md` の「フォーム発見アルゴリズム」に従う）。
   - 公式URLのサイトを取得し、`お問い合わせ/問い合わせ/contact/inquiry/otoiawase` 等のリンクを辿ってフォームページを特定。
   - 楽天・Yahoo等の**モール店URL**は独立フォームを持たないことが多いので、運営会社の自社サイトを探し、
     それでも無ければ **「ー」** とする（判定ルールは `SPEC.md` 参照）。
4. **H列へ直接書き込み**: 見つかればそのURL、見つからなければ「ー」。**既存値は絶対に上書きしない**。
   - 書き込みと同時に、処理ログ（行番号・会社名・結果URL・判定理由）をCSV/ログに残す。
5. **重複調査の回避**: 添付 `baseline_results.csv`（過去に人手＋AIで調査済みの392件）を初期データとして読み込み、
   同じ行（または同じ公式URL）は再調査せず、その結果を流用してよい。
6. **毎日12時(JST)に自動実行**する仕組みを用意する（`SPEC.md` の「スケジューリング」から1つ選んで実装）。
7. **冪等・安全**に作る: 途中失敗しても再実行で続きから。APIレート制限・リトライ・礼儀正しいクロール(UA設定・間隔)を守る。
