# company-settings.md — 企業設定ファイル

このファイルは、**利用企業が自社に合わせて書き換えるための設定ファイル**です。
各項目の「:」の右側を書き換えるだけでカスタマイズできます。
空欄のままの項目は、括弧内の初期値(デフォルト)が使われます。

> 書き換えてよいのは原則このファイルだけです。
> 処理ルール(processing-rules.md)やセキュリティルール(security-rules.md)は変更しないでください。

---

# 会社情報

会社名:株式会社サンプル商事(デモ用の架空企業。導入時に自社名へ変更してください)
部署名:営業部
日報作成者名:(空欄の場合、チャットから読み取れる場合のみ記載。読み取れなければ「不明」)

# 入力設定

利用するチャットツール:指定なし(初期版はコピー&ペーストしたテキストを対象。ツール名を書くと発言形式の読み取り精度が上がります)
日報の対象:業務に関する発言すべて(会議、顧客対応、社内依頼、決定事項、タスク、課題、翌日の予定)
日報の対象外:雑談、あいさつのみの投稿、スタンプ・リアクションのみの投稿、個人的な予定
対象期間:当日分(チャットに複数日が含まれる場合は、最新の日付の分を対象とする)

# 日報設定

日報タイトル:業務日報
日報に含める項目:daily-report-template.md のすべての項目(基本情報/本日の主な業務/実施内容・進捗/顧客対応/社内対応/決定事項/未完了・継続タスク/課題・懸念事項/明日の予定/要確認事項)
日報に含めない項目:なし(不要な項目があれば、ここに項目名を書いてください。例:顧客対応)
文体:です・ます調(敬体)
文字量:標準(A4で1ページ以内を目安。「簡潔」「詳細」も指定できます)
箇条書きの利用:利用する
表の利用:利用する(未完了・継続タスクは表形式)

# 表記設定

顧客名の表記方法:「◯◯様」(会社名+様。例:ABC商事様)
社員名の表記方法:「◯◯さん」(姓+さん。例:田中さん)
社内用語:なし(社内用語と意味を「用語=意味」の形で列挙すると、日報で正しく使われます)
略語:なし(略語と正式名称を「略語=正式名称」の形で列挙してください。例:MTG=打ち合わせ)

# セキュリティ設定

記載禁止情報:パスワード、認証情報、APIキー、口座番号、クレジットカード番号、マイナンバー
匿名化が必要な情報:業務に関係のない個人の氏名、個人の電話番号・メールアドレス・住所
削除が必要な情報:健康状態・家族などのプライベートな話題、業務と無関係な個人情報

※ ここに項目を追加しても、security-rules.md の基本ルールは常に適用されます(設定で緩めることはできません)。

# 出力設定

出力形式:Markdown(Google Docs へそのまま貼り付けられる形式)
ファイル名ルール:YYYY-MM-DD_業務日報_担当者名(例:2026-07-13_業務日報_田中)
保存先:利用者が手動で Google Docs へ貼り付け(初期版では自動保存は行いません)
