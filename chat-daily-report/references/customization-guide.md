# customization-guide.md — カスタマイズ手引き

このファイルは、利用企業がスキルを自社用に調整する方法を説明します。
プログラミングの知識は不要です。テキストファイルを編集するだけで調整できます。

---

## 1. カスタマイズの基本方針

| 変更したいこと | 編集するファイル |
|---|---|
| 会社名・部署名・担当者名 | `company-settings.md` |
| 日報に含める項目・含めない項目 | `company-settings.md` |
| 文体(です・ます調/である調)、文字量 | `company-settings.md` |
| 顧客名・社員名の表記、社内用語・略語 | `company-settings.md` |
| 記載禁止情報の追加 | `company-settings.md`(セキュリティ設定) |
| 日報の見出し構成・並び順を大きく変える | `daily-report-template.md` |
| 抽出・除外の判断ルール | 変更しないでください(`processing-rules.md`) |
| セキュリティの基本ルール | 変更しないでください(`security-rules.md`) |

**原則:まず `company-settings.md` だけを編集してください。**
それで足りない場合のみ `daily-report-template.md` を編集します。

## 2. company-settings.md の編集方法

1. `references/company-settings.md` を開く
2. 各項目の「:」の右側を自社の内容に書き換える
3. 分からない項目は空欄のままにする(初期値が使われます)
4. 保存して、スキルを再登録(またはファイルを再アップロード)する

### よくあるカスタマイズ例

**例1:文体を「である調」に変える**

```
文体:である調(常体)
```

**例2:顧客名をイニシャル表記にする(社外に見せる可能性がある場合)**

```
顧客名の表記方法:イニシャル表記(例:A社様)
```

**例3:社内用語を登録する**

```
社内用語:定例=毎週月曜の部内定例会議、CS=カスタマーサポート部
略語:MTG=打ち合わせ、FB=フィードバック
```

**例4:「顧客対応」欄が不要な部署(経理部など)**

```
日報に含めない項目:顧客対応
```

## 3. daily-report-template.md の編集方法(上級)

日報の見出し名や並び順を大きく変えたい場合に編集します。

1. `references/daily-report-template.md` の「テンプレート本体」のコードブロック内を編集する
2. 見出し(`##`)の追加・削除・並び替えができる
3. **「要確認事項」と「Claudeによる確認結果」は削除しないでください**(推測禁止ルールの受け皿のため)

## 4. 設定変更で対応できること・できないこと

### 設定変更だけで対応できること

- 会社名・部署名・表記ルール・用語の変更
- 日報の項目の増減、文体・文字量の調整
- 記載禁止情報の追加
- 日報タイトル・ファイル名ルールの変更

### 設定変更だけでは対応できないこと(開発・追加作業が必要)

- チャットツールからの履歴の自動取得(手動コピー&ペーストが必要)
- Google Docs への自動保存(`optional-integration/` のサンプルを参照)
- 週報・月報など、日報以外の帳票の作成
- 複数人分の日報の一括作成
- チャット以外の情報源(メール・カレンダー等)からの抽出

## 5. カスタマイズ後の確認方法

1. `assets/demo-chat.txt` を使って日報を作成してみる
2. 設定変更が反映されているか確認する
3. 問題があれば設定を見直し、再度試す

## 6. 困ったときは

- 設定を初期状態に戻したい:このスキル一式を再取得し、`company-settings.md` を置き換える
- 出力が期待と違う:設定項目の書き方が曖昧でないか確認する(具体例を書くと精度が上がります)
- それでも解決しない場合:README.md の「サポートが必要になるケース」を参照
