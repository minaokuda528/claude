# daily-report-template.md — 日報テンプレート

このファイルは、日報の出力形式を定義するテンプレートです。
形式を変更したい場合は、このテンプレートを編集するか、
`company-settings.md` の「日報に含める項目/含めない項目」で調整してください。

## テンプレートの使い方(Claude 向けルール)

- 下記テンプレートの構成・見出し・並び順のとおりに日報を作成する。
- `company-settings.md` に別のフォーマットや項目の増減が指定されている場合は、**設定ファイルを優先**する。
- 該当する情報がチャットにない項目は、削除せず「特になし」と記載する(項目の抜け漏れと区別するため)。
- 担当者・期限が不明な場合は「不明」と記載し、「要確認事項」にも挙げる。
- 日報本文の後に、必ず「Claudeによる確認結果」を付ける。

## テンプレート本体

```markdown
- 担当者:
- 部署:

## 本日の主な業務

1.
2.
3.

## 実施内容・進捗

- 現在の状況:
- 関係者:

-

-

| タスク | 担当者 | 期限 | 状況 |
|---|---|---|---|
| | | | |

## 課題・懸念事項

-

-

## 要確認事項

```

## 日報の後に必ず付ける確認結果

```markdown
## Claudeによる確認結果

- 推測して追加した情報:なし
- 要確認事項:
- 日報から除外した情報:
- 情報不足により記載できなかった項目:
```

## 各項目の記載基準

| 項目 | 記載する内容 |
|---|---|
| 基本情報 | 日付(チャットの日付)、担当者(設定ファイルまたはチャットから)、部署(設定ファイルから) |
| 本日の主な業務 | その日の中心的な業務を最大5件、重要度順に |
| 実施内容・進捗 | 業務ごとに「実施内容/現在の状況/関係者」を整理 |
| 顧客対応 | 顧客との打ち合わせ・連絡・要望対応など |
| 社内対応 | 社内の依頼・報告・調整など |
| 決定事項 | 確定した事項のみ。後から変更された場合は最新の内容を採用 |
| 未完了・継続タスク | 完了報告のないタスク。担当者・期限が不明なら「不明」 |
| 課題・懸念事項 | チャットで言及された問題点・リスク |
| 明日の予定 | 翌日の予定として明言されたもののみ |
| 要確認事項 | 担当者不明・期限不明・判断できなかった事項 |
