# chat-daily-report — チャットから業務日報を作成する Claude スキル

> **注意:これは開発中の仮バージョンの README です。**
> 正式なマニュアルはフェーズ5で作成します。

## 概要

社内チャットの履歴を Claude に渡すと、その日の業務内容・決定事項・未完了タスク・課題・翌日の予定を整理し、
Google Docs へ貼り付けられる業務日報を作成するスキルです。

- チャットに書かれていない情報は推測しません(担当者・期限が不明な場合は「不明」と明記)。
- 雑談・重複投稿・個人情報・パスワードなどは日報に含めません。
- 企業ごとの調整は `references/company-settings.md` を編集するだけで行えます。
- 初期版では Slack / Chatwork / Teams / Google Docs との API 連携は行いません(オプションとして分離)。

## 開発フェーズ

| フェーズ | 内容 |
|---|---|
| 0 | プロジェクト初期化(フォルダ・管理ルール作成) |
| 1 | 要件定義(設定ファイル・処理ルール・テンプレート) |
| 2 | デモデータ作成(架空チャットと正解日報) |
| 3 | SKILL.md 作成(スキル本体) |
| 4 | 動作テストと修正 |
| 5 | 利用者向けマニュアル作成(この README を完成させる) |
| 6 | Google Docs 連携サンプル(オプション) |
| 7 | 最終確認・納品準備 |

## フォルダ構成

```text
chat-daily-report/
├── CLAUDE.md                 … プロジェクト管理ルール
├── README.md                 … 利用者向けマニュアル(このファイル)
├── SKILL.md                  … スキル本体(フェーズ3で作成)
├── agents/                   … エージェント定義(フェーズ3で作成)
├── references/               … 設定・ルールファイル(フェーズ1で作成)
├── assets/                   … デモデータ・テストケース(フェーズ2で作成)
├── optional-integration/     … Google Docs 連携サンプル(フェーズ6で作成)
└── test-results/             … テスト結果(フェーズ4で作成)
```

## 想定する利用手順(完成後)

1. スキル一式を Claude へ登録する
2. `references/company-settings.md` に自社情報を入力する
3. 当日のチャット履歴を Claude へ渡す
4. 「今日の業務日報を作成してください」と依頼する
5. Claude が重要な不足情報だけを質問する(最大3問)
6. 回答すると Claude が業務日報を作成する
7. 内容を確認して Google Docs へ貼り付ける
