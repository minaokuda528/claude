# test-cases.md — テストケース定義

`demo-chat.txt` を入力してスキルを実行した際の、確認項目と期待結果の一覧です。
フェーズ4の動作テストで使用します。結果は `test-results/test-report.md` に記録します。

## テストの前提

- 入力:`assets/demo-chat.txt`
- 設定:`references/company-settings.md`(初期値のまま)
- 正解:`assets/demo-daily-report.md`
- 不足情報の質問には回答しない(未回答でも日報が作成されることを確認)

## 合格基準(フェーズ4で判定)

- 主要業務の抽出漏れがない
- 決定事項の誤認がない
- 未完了タスクの重大な漏れがない
- 雑談・個人情報が日報へ含まれていない
- 担当者・期限を勝手に補完していない
- 正解日報(demo-daily-report.md)と大きな矛盾がない
