# customer-checklist.md — 導入チェックリスト

利用開始前に、このチェックリストで準備状況を確認してください。
プログラミングの知識は不要です。

## 1. 導入準備

- [ ] `chat-daily-report` 一式を用意した
- [ ] Claude にスキル一式を登録した(`SKILL.md` と `references/` が読み込まれる状態)
- [ ] デモデータ(`assets/demo-chat.txt`)で一度動作を確認した

## 2. 設定(`references/company-settings.md`)

- [ ] 会社名を入力した
- [ ] 部署名を入力した
- [ ] 日報作成者名を入力した(またはチャットから読み取る運用にした)
- [ ] 顧客名の表記方法を確認した(社外共有の可能性があればイニシャル表記を検討)
- [ ] 社員名の表記方法を確認した
- [ ] 文体(です・ます調/である調)を確認した
- [ ] 社内用語・略語があれば登録した
- [ ] 記載禁止情報に、自社で追加すべき項目があれば追記した

## 3. セキュリティ確認

- [ ] チャットを渡す前に機密情報を確認する運用を決めた
- [ ] 日報の保存先(Google Docs 等)の共有範囲を確認する運用を決めた
- [ ] 「最終確認は人が行う」ことをチーム内で共有した

## 4. 運用ルール

- [ ] 誰が・いつ日報を作成するか決めた
- [ ] 不足情報の質問への回答方法を決めた(回答する/スキップして要確認のまま作成する)
- [ ] Google Docs への貼り付け・保存の手順を共有した
- [ ] 自動化(Google Docs連携など)が必要かを検討した(`optional-integration/` 参照)

## 5. 試運転

- [ ] 実際の1日分のチャットで日報を作成してみた
- [ ] 「Claudeによる確認結果」の内容を確認した
- [ ] 出力に事実と異なる記載がないか人の目で確認した
- [ ] 必要に応じて `company-settings.md` を微調整した
