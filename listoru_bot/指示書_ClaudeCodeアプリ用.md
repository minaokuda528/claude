# リストル収集予約 自動処理 — Claude Code アプリ用 指示書

このファイルの内容を **Claude Code アプリ（自分のPCで動くもの）** に貼り付けて指示してください。
自分のPCから実行するので、対象サイトにそのまま接続できます（Webのリモート環境のような接続制限がありません）。

## Claude への依頼文（ここから下をそのままコピペ）

あなたはブラウザ（Playwright）を操作して、リストルの収集予約一覧にある予約を **下から順番に** 処理します。
まずは仕組みの確認を優先し、**いきなり全件は実行せず、必ず1件だけ試してから**全件に進んでください。

### 対象サイト
https://www.listoru814.list1.xyz/main.php

### ログイン情報
- ID：`（ここに自分のIDを入れる）`
- パスワード：`（ここに自分のパスワードを入れる）`
（パスワードはログインにのみ使い、コード・ログ・コミットには絶対に書き込まないでください）

### やること
各予約について次を行い、**CSVのダウンロード完了を確認できた予約だけ**を一覧から削除する。
これを収集予約一覧が空になるまで繰り返す。

1. ログイン →「収集予約一覧（照会）」を開く
2. 一覧の **一番下** の予約を対象にする（収集サイト名・収集条件・削除ボタン位置を記録）
3. 収集実行画面で、同じ収集サイト名・収集条件を設定し、**最大収集閾値＝2000件**にする
4. 「検索開始」を1回だけ押す → 2分待つ
5. 「収集開始」が押せたら1回だけ押す（押せなければ2分待って再確認、最大3回。ダメなら削除せずスキップしてログに「収集開始不可」）
6. 収集完了を待つ（**最初の15分は待機 → その後5分間隔で確認 → 最大60分**。60分で完了しなければ削除せずスキップし「収集完了タイムアウト」と記録）
7. 「CSV出力」→ 表示された **チェック項目をすべてチェック** → CSV出力を実行
8. CSVのダウンロード完了を確認（ファイルが存在し、0KBでない）
9. **ダウンロードを確認できた場合のみ**、一覧に戻り、同じ収集サイト名・収集条件の行のうち **一番下** を、直前にCSV出力した予約と一致することを再確認してから削除
10. 削除後、一覧を再表示して該当予約が消えたことを確認

### 絶対に守るルール
- CSVのダウンロード完了を確認できない予約は **絶対に削除しない**
- 失敗・収集開始不可・60分タイムアウト・CSV失敗の予約は、削除せずスキップし、ログに理由を残す
- 収集中は画面を確認しすぎない・同じボタンを連打しない・不要な再読み込みをしない（クレジット節約のため）
- どの予約を処理中か分からなくなったら停止して私に確認する

### 進め方（コスト＝クレジットを抑えるため必ずこの順で）
1. まず **ログインして画面構造だけ調査**（収集開始ボタンは押さない）。ログインフォーム・メニュー・一覧・収集実行画面・CSV出力画面の各要素（入力欄名やボタン名、selectの選択肢、一覧の列構成）を調べて私に報告する
2. その結果に合わせて操作スクリプトを作る（Playwright、Python でよい）
3. **まず1件だけ本番実行**して、収集→CSV→ダウンロード→削除の全工程が正しく動くか確認する
4. 問題なければ、残りを全件処理する

### ログと最終報告
各予約について以下を記録：
処理番号 / 処理開始時刻 / 収集サイト名 / 収集条件 / 最大収集閾値2000件 / 検索開始結果 / 収集開始結果 /
収集完了結果 / CSV出力結果 / CSVファイル名 / 予約削除結果 / エラー・補足

最後に以下を報告：
処理件数 / CSV出力成功件数 / 削除成功件数 / スキップ件数 / スキップした予約の詳細 /
ダウンロードされたCSVファイル一覧 / 作業中に発生した問題

## （任意）既に作ってあるスクリプトを使う場合

この指示書と同じフォルダに、すでに動作する雛形スクリプト `listoru_bot.py` があります。
Claude Code アプリで使うなら、次のように伝えると早いです：

> 同じフォルダの `listoru_bot.py` と `README.md` を読んで。これはリストル収集予約を下から順に処理する雛形。
> まず `python3 listoru_bot.py --inspect` を実行して、保存された `inspect/*_fields.txt` を見て
> `config.json` のセレクタと `site_and_condition()` の列番号を実サイトに合わせて直して。
> 次に `python3 listoru_bot.py --dry-run` で読み取りを確認し、
> 問題なければ `python3 listoru_bot.py --run --limit 1` で1件だけ試して、
> それも成功したら `python3 listoru_bot.py --run` で全件やって。

事前準備（アプリ側のターミナルで一度だけ）：
```bash
pip install playwright
playwright install chromium
export LISTORU_ID='自分のID'
export LISTORU_PASSWORD='自分のパスワード'
```
（Windowsの場合は `set LISTORU_ID=自分のID` / `set LISTORU_PASSWORD=自分のパスワード`）
